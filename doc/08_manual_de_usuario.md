# 08. Manual de usuario
## Proyecto: PetCare Santa Cruz

### 1. Introducción

El presente manual explica el funcionamiento de PetCare Santa Cruz y describe las principales operaciones disponibles para cada tipo de usuario.

La aplicación permite gestionar información de mascotas y acceder a servicios veterinarios mediante tres perfiles: cliente, veterinario y administrador.

Cada perfil dispone de funcionalidades específicas según sus permisos. Además, determinados módulos incorporan actualizaciones en tiempo real para mantener la información sincronizada.

### 2. Acceso a la aplicación

Al abrir PetCare, el usuario puede acceder a las opciones de autenticación disponibles.

#### 2.1. Registro de usuario

1. Abrir la aplicación.
2. Seleccionar la opción de registro.
3. Completar los datos personales solicitados.
4. Introducir un correo electrónico y una contraseña.
5. Enviar el formulario.
6. Revisar el correo electrónico recibido.
7. Seguir el enlace de confirmación para activar la cuenta.

Los nuevos usuarios se registran con el perfil de cliente.

#### 2.2. Inicio de sesión

1. Abrir la pantalla de inicio de sesión.
2. Introducir el correo electrónico.
3. Introducir la contraseña.
4. Seleccionar la opción para ingresar.
5. El sistema identificará el perfil y mostrará las opciones correspondientes.

#### 2.3. Recuperación de contraseña

1. Acceder a la opción de recuperación de contraseña.
2. Introducir el correo electrónico registrado.
3. Solicitar el enlace de recuperación.
4. Revisar el correo electrónico recibido.
5. Seguir las instrucciones para establecer una nueva contraseña.

### 3. Funcionalidades del cliente

El cliente puede acceder a los módulos destinados a la gestión y cuidado de sus mascotas.

#### 3.1. Inicio

Presenta la pantalla principal y permite acceder a las diferentes secciones de la aplicación.

También muestra información resumida sobre las mascotas, reservas, registros médicos y notificaciones de la cuenta.

#### 3.2. Registro de mascotas

1. Ingresar al módulo de mascotas.
2. Seleccionar la opción de registrar.
3. Completar la información solicitada, como nombre, especie, raza y otros datos.
4. Guardar el registro.
5. Consultar la mascota en el listado correspondiente.

Las mascotas registradas quedan asociadas a la cuenta del propietario.

#### 3.3. Servicios veterinarios

Permite consultar los servicios disponibles y conocer su descripción, precio y duración cuando estos datos estén registrados.

#### 3.4. Reservas de citas

1. Ingresar al módulo de reservas.
2. Seleccionar el servicio.
3. Elegir la mascota correspondiente, cuando corresponda.
4. Completar los datos solicitados.
5. Enviar la solicitud.
6. Consultar posteriormente el estado de la reserva.

Las reservas pueden presentar estados como pendiente, confirmada, atendida o cancelada.

El cliente puede solicitar la cancelación de sus propias reservas mediante la opción habilitada en la aplicación.

#### 3.5. Control de vacunas

Permite consultar la información relacionada con las vacunas registradas para las mascotas.

#### 3.6. Historial médico

Permite consultar los registros médicos disponibles de las mascotas del cliente, incluyendo información como diagnósticos, tratamientos y observaciones cuando se encuentren registrados.

#### 3.7. Tienda

Permite visualizar los productos disponibles relacionados con el cuidado de las mascotas.

Se puede consultar información como:

- Nombre del producto.
- Descripción.
- Categoría.
- Precio.
- Disponibilidad de stock.
- Imagen del producto, cuando esté registrada.

Los productos desactivados por el administrador dejan de aparecer en la tienda.

#### 3.8. Carrito de compras

Permite seleccionar productos de la tienda y preparar un pedido.

Las operaciones disponibles incluyen:

1. Seleccionar un producto.
2. Agregarlo al carrito.
3. Consultar los productos seleccionados.
4. Revisar las cantidades y el total.
5. Modificar o retirar productos del carrito, según las opciones disponibles.
6. Confirmar el pedido.

#### 3.9. Pedidos

Después de confirmar una compra, el cliente puede consultar sus pedidos y revisar información como:

- Total del pedido.
- Fecha de registro.
- Estado del pedido.

El estado permite conocer el avance del pedido según la información registrada por el sistema.

#### 3.10. Consultas y contacto

El módulo de consultas permite enviar mensajes al personal de PetCare.

Para registrar una consulta:

1. Ingresar al módulo de consultas.
2. Completar el nombre y número de teléfono.
3. Escribir el mensaje correspondiente.
4. Enviar la consulta.

También se puede acceder a la sección de contacto para consultar las opciones de comunicación disponibles.

#### 3.11. Mapa de veterinarias

Permite visualizar la ubicación de los negocios veterinarios registrados en el sistema.

El mapa utiliza OpenStreetMap y muestra las ubicaciones mediante sus coordenadas geográficas.

El cliente puede seleccionar una ubicación y utilizar las opciones disponibles para contactar al negocio o consultar cómo llegar.

#### 3.12. Clima

Permite consultar información meteorológica actual mediante el servicio Open-Meteo.

Entre los datos que puede mostrar se encuentran:

- Clima actual.
- Sensación térmica.
- Humedad.
- Velocidad del viento.
- Precipitación.

La información depende de la disponibilidad del servicio y de la conexión a internet.

#### 3.13. Notificaciones

Permite consultar avisos relacionados con las actividades de la cuenta, como:

- Cambios en el estado de las reservas.
- Nuevos registros médicos.
- Actualizaciones y avisos de pedidos.
- Otros avisos generados por el sistema.

### 4. Funcionalidades del veterinario

El perfil veterinario dispone de herramientas para consultar información y gestionar actividades relacionadas con la atención médica.

#### 4.1. Panel veterinario

Permite acceder a los módulos correspondientes al trabajo del veterinario y consultar información relacionada con las mascotas y las citas.

#### 4.2. Consulta de mascotas

1. Ingresar al módulo de mascotas.
2. Buscar o seleccionar una mascota.
3. Consultar sus datos y detalles disponibles.

El veterinario puede consultar información de las mascotas registradas en el sistema.

#### 4.3. Historial médico

1. Seleccionar una mascota.
2. Acceder a su historial médico.
3. Revisar los registros disponibles.
4. Consultar los antecedentes médicos registrados.

#### 4.4. Registro médico

1. Seleccionar la mascota correspondiente.
2. Acceder a la opción de registrar información médica.
3. Completar los datos del registro.
4. Introducir el diagnóstico, tratamiento, vacuna u observaciones, según corresponda.
5. Guardar la información.
6. Verificar que el registro aparezca en el historial.

Los registros quedan asociados al veterinario que los realiza y al propietario de la mascota correspondiente.

#### 4.5. Gestión de citas

Permite consultar las reservas registradas y actualizar su estado según los permisos asignados.

El veterinario puede revisar la información de las citas y mantener actualizado su estado.

#### 4.6. Notificaciones

Permite consultar los avisos relacionados con nuevas reservas y otras actividades del sistema.

### 5. Funcionalidades del administrador

El administrador dispone de herramientas para gestionar diferentes elementos del sistema desde el panel administrativo.

#### 5.1. Panel administrativo

Presenta las opciones de administración y muestra indicadores generales sobre usuarios, mascotas y reservas.

Los indicadores se actualizan cuando se producen cambios en los módulos correspondientes.

#### 5.2. Gestión de usuarios

Permite consultar los perfiles registrados y administrar sus roles de acuerdo con los permisos establecidos.

El administrador puede asignar los siguientes roles:

- Cliente.
- Veterinario.
- Administrador.

#### 5.3. Gestión de mascotas

Permite consultar las mascotas registradas en el sistema.

Incluye opciones para:

- Buscar mascotas por nombre, especie o raza.
- Consultar información del propietario.
- Visualizar los detalles de cada mascota.
- Consultar indicadores generales de mascotas registradas.

#### 5.4. Gestión de servicios

Permite administrar los servicios veterinarios disponibles.

Sus operaciones incluyen:

- Registrar nuevos servicios.
- Editar información de servicios existentes.
- Activar o desactivar servicios.
- Consultar indicadores de servicios activos e inactivos.

#### 5.5. Gestión de reservas

Permite consultar y administrar las reservas registradas.

Incluye:

- Consultar las reservas.
- Buscar y filtrar registros.
- Revisar los detalles de cada reserva.
- Cambiar el estado de las reservas según las opciones disponibles.

Los estados disponibles son pendiente, confirmada, atendida y cancelada.

#### 5.6. Gestión de consultas

Permite revisar los mensajes enviados por los clientes.

El administrador puede:

- Consultar las consultas recibidas.
- Buscar registros.
- Revisar los detalles de cada mensaje.
- Cambiar el estado entre pendiente y atendida.
- Utilizar la opción de contacto por WhatsApp cuando corresponda.

#### 5.7. Gestión de productos

Permite administrar los productos que aparecen en la tienda de PetCare.

Sus operaciones incluyen:

- Registrar nuevos productos.
- Editar nombre, descripción, categoría, precio e imagen.
- Actualizar el stock disponible.
- Activar o desactivar productos.
- Consultar indicadores de productos totales, activos, inactivos y sin stock.

Los productos activos aparecen en la tienda del cliente.

#### 5.8. Gestión de pedidos

Permite consultar los pedidos registrados por los clientes.

El administrador puede:

- Consultar los pedidos recibidos.
- Revisar el usuario que realizó el pedido.
- Consultar el total y la fecha de registro.
- Revisar el estado de cada pedido.
- Gestionar la información del pedido según las opciones habilitadas.

#### 5.9. Gestión de negocios veterinarios

Permite administrar la información de los negocios que aparecen en el mapa de veterinarias.

Los registros pueden contener:

- Nombre del negocio.
- Número de teléfono.
- Latitud.
- Longitud.

Esta información permite mostrar las ubicaciones en el mapa y facilitar el contacto con los negocios registrados.

#### 5.10. Reportes y estadísticas

Permite consultar información resumida sobre el funcionamiento del sistema.

Incluye datos relacionados con:

- Usuarios registrados.
- Mascotas por especie.
- Reservas por estado.
- Servicios solicitados.
- Atenciones médicas registradas.

#### 5.11. Notificaciones

Permite consultar avisos administrativos relacionados con nuevas reservas, registros de clientes, pedidos y otras actividades del sistema.

### 6. Seguridad y recomendaciones

Para utilizar PetCare Santa Cruz de manera adecuada, se recomienda seguir estas indicaciones:

- Mantener las credenciales de acceso en privado.
- Utilizar contraseñas seguras.
- Cerrar sesión al terminar de utilizar la aplicación.
- Introducir información correcta en los formularios.
- Consultar los registros médicos antes de tomar decisiones relacionadas con la atención de una mascota.
- Utilizar únicamente las funciones habilitadas para el perfil correspondiente.
- No compartir cuentas de administrador o veterinario.
- Verificar los datos de los productos y pedidos antes de confirmar una compra.
- Comprobar la información de contacto antes de realizar llamadas o enviar mensajes.
- Mantener conexión a internet para utilizar las funciones que dependen de Supabase y servicios externos.
- Tener en cuenta que el mapa y la información meteorológica dependen de servicios externos.
- Mantener actualizada la aplicación cuando se publiquen nuevas versiones.

### 7. Consideraciones finales

PetCare Santa Cruz proporciona herramientas para centralizar la gestión del cuidado de mascotas y facilitar la interacción entre clientes, veterinarios y administradores.

La aplicación integra funcionalidades para:

- Registrar y administrar mascotas.
- Consultar servicios y gestionar reservas.
- Consultar vacunas e historiales médicos.
- Visualizar productos y realizar pedidos mediante el carrito de compras.
- Enviar consultas y recibir notificaciones.
- Localizar negocios veterinarios mediante un mapa basado en OpenStreetMap.
- Consultar información meteorológica mediante Open-Meteo.
- Facilitar la comunicación con negocios mediante WhatsApp y llamadas telefónicas.

La aplicación utiliza Supabase como backend para gestionar la autenticación y los datos del sistema.

Además, incorpora mecanismos de actualización en tiempo real en los módulos correspondientes, permitiendo que determinados cambios realizados por otros usuarios se reflejen sin necesidad de salir y volver a ingresar a la pantalla.

Las opciones disponibles pueden variar según el rol del usuario y las funcionalidades habilitadas en la versión instalada. Algunas operaciones requieren conexión a internet y disponibilidad de los servicios externos.
